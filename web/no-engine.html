This is the same tic-tac-toe-lib that drives the terminal, the bracket-lib console, Bevy's ECS and Godot's scene tree — here with no game engine at all, drawing to a 2D canvas through wasm-bindgen. The rules crate is unchanged and this page contains no rule of the game: whether a square is playable, who has won and whose turn it is are all answers the library gives.

The Bevy build of this same game is next door. Comparing the two downloads is the point: an engine buys you an ECS, a renderer, asset loading and an input abstraction, and it is worth having when you need them. When you do not, this is what the same game costs.
